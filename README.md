# Expense Tracker TypeScript — Shayan Ghane

A complete, responsive personal finance dashboard built for **HW-L04-01: TypeScript**. This version preserves the full feature set of the previous Expense Tracker project and migrates the source to **TypeScript (`.ts` / `.tsx`)** with reusable domain models, typed calculations, typed CSV processing, typed Redux hooks, and typed UI context.

## Google Authentication setup

Local login works without external configuration. Google Sign-In requires Firebase:

1. Create a Firebase project.
2. Enable **Authentication → Sign-in method → Google**.
3. Register a Firebase Web App.
4. Copy `.env.example` to `.env`.
5. Add the Firebase values.

```env
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=
```

## Import and export rules

### CSV

CSV import validates:

- Required headers
- Positive amount
- `income` or `expense` transaction type
- Valid date
- Existing category and wallet
- Duplicate transactions

### PDF

PDF export creates a financial report and embeds a versioned application backup. For predictable parsing, PDF import accepts only a PDF generated by this application.

Google Sign-In uses Firebase Authentication and is the real external authentication option included in this project.
